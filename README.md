# 📱 LotsOpenAPKs

A huge, organized directory for discovering Android applications, FOSS projects, utilities, launchers, browsers, media apps, developer tools, customization tools, games, and more.

> **⚠️ APK safety:** Prefer the developer's official release, F-Droid, Google Play, or a well-established repository. Check the publisher, package name, permissions, release history, signatures/checksums, and source code when available. LotsOpenAPKs is a discovery list and does not guarantee that every third-party download is safe.

## 🧭 How to Find Good Apps

1. **Start with the official project page** when possible.
2. For FOSS apps, check **F-Droid, Fossdroid, and IzzyOnDroid**.
3. For developer releases, check **GitHub, GitLab, Codeberg, or SourceHut**.
4. Use established APK archives when an official source is unavailable.
5. Compare the **package name, publisher, version, permissions, and signing information** before installing.
6. Be cautious with modified or reuploaded APKs where the original developer cannot be verified.
7. Keep apps updated and remove applications you no longer trust or need.

## 🤝 Contributing

Want to add an app?

1. Put it in the most appropriate category.
2. Include a short description.
3. Link to the official project/developer page whenever possible.
4. Mention F-Droid, GitHub, GitLab, or another reputable source if available.
5. Do not intentionally add malicious, deceptive, or obviously suspicious software.
6. Open a pull request with your addition.

## ⭐ Goal

**LotsOpenAPKs** aims to become a massive, organized starting point for discovering Android software — from tiny FOSS utilities to full-featured apps, launchers, browsers, games, media players, developer tools, and everything between.

> 💡 This is a discovery directory, not a guarantee of app safety. Always check an app's source, license, publisher, permissions, update history, and download provenance before installing it.
