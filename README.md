# 📱 LotsOpenAPKs

A huge, organized directory for discovering Android applications, FOSS projects, utilities, launchers, browsers, media apps, developer tools, customization tools, games, and more.

> **⚠️ APK safety:** Prefer the developer's official release, F-Droid, Google Play, or a well-established repository. Check the publisher, package name, permissions, release history, signatures/checksums, and source code when available. LotsOpenAPKs is a discovery list and does not guarantee that every third-party download is safe.

## 🔗 How the links work

Most app names below are clickable. They point to an official project page, source repository, F-Droid listing, Google Play listing, or another established download/view page. **The preferred link is the official developer source whenever one is available.**

## 🧭 How to use this list

- **Official link first:** Prefer the developer's own website or repository.
- **FOSS:** Check F-Droid, Fossdroid, IzzyOnDroid, or the upstream repository.
- **Git releases:** Look under the project's Releases page for APKs when available.
- **Mirrors:** If using an APK mirror, compare the package name, version, publisher, and signing information.
- **Unknown APKs:** Treat modified/repacked APKs with extra caution.
- **Keep it current:** If an app moves repositories or changes its official download page, update its link.

## 🤝 Contributing

1. Add the app to the best category.
2. Make the app name a Markdown link to its best official/reputable page.
3. Include a short description.
4. Prefer upstream, F-Droid, Google Play, GitHub, GitLab, Codeberg, or another reputable source.
5. Avoid suspicious reuploads and links with unclear provenance.
6. Open a pull request.

## ⭐ Goal

**LotsOpenAPKs** aims to become a massive, organized starting point for discovering Android software — with clickable paths to official pages, repositories, release pages, F-Droid listings, and other useful sources.

> 💡 This is a discovery directory, not a guarantee of app safety. Always check an app's source, license, publisher, permissions, update history, and download provenance before installing it.
