# 📱 LotsOpenAPKs

A huge, organized directory for discovering Android applications, FOSS projects, utilities, launchers, browsers, media apps, developer tools, customization tools, games, and more.

> **⚠️ APK safety:** Prefer the developer's official release, F-Droid, Google Play, or a well-established repository. Check the publisher, package name, permissions, release history, signatures/checksums, and source code when available. LotsOpenAPKs is a discovery list and does not guarantee that every third-party download is safe.

## 🔗 How the links work

Most app names below are clickable. Links point to an official project page, source repository, F-Droid listing, Google Play listing, or established download/view page. **Prefer the official developer source whenever one is available.**

## 🔍 How to use this list

1. Pick a category.
2. Click an app name to open its project, source, or download page.
3. Prefer official developer releases or established repositories.
4. For FOSS apps, check the source repository and F-Droid/IzzyOnDroid listing when available.
5. For apps distributed outside a store, compare the package name, signing information, version, and release notes before installing.

## 🤝 Contributing

Want to add an app? Open a pull request and include:

Please avoid dead links, obvious mirrors, misleading download pages, and duplicate entries.
